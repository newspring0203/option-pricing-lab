# 16. 몬테카를로로 옵션가치를 계산해봅시다 — 실제 주가 데이터와 Black–Scholes 비교

앞선 글에서는 기업의 미래 현금흐름을 추정하고, 할인율과 성장률을 바꾸면서 가치가 얼마나 달라지는지 살펴봤습니다.

이번에는 불확실성을 다루는 계산 방법을 직접 구현해보겠습니다. 대상으로는 AAPL의 실제 과거 주가와 가상의 유럽형 콜옵션을 선택했습니다.

질문은 다음과 같습니다.

**“가능한 만기 주가를 반복해서 생성하고 옵션의 지급액을 평균 내면, 공식으로 계산한 옵션가치와 비슷한 결과를 얻을 수 있을까요?”**

실제로 Python으로 100만 번 계산한 결과는 약 **12.4146달러**, 같은 입력을 사용한 Black–Scholes 값은 약 **12.4192달러**였습니다. 이 숫자들이 어떻게 나왔는지, 무엇을 검증한 결과인지 차례로 살펴보겠습니다.

## 1. 왜 유럽형 콜옵션부터 시작할까요?

콜옵션은 정해진 가격으로 기초자산을 살 수 있는 권리입니다. 유럽형은 그 권리를 **만기에만 행사할 수 있다**는 뜻입니다. 거래 지역을 의미하는 말은 아닙니다.

행사가격이 250달러라면 만기 주가에 따른 지급액은 다음과 같습니다. 금액은 모두 기초주식 1주에 대응하는 기준입니다.

| 만기 주가 | 행사가격 | 만기 지급액 |
|---|---:|---:|
| 220달러 | 250달러 | 0달러 |
| 250달러 | 250달러 | 0달러 |
| 280달러 | 250달러 | 30달러 |

수식으로는 `max(만기 주가 − 행사가격, 0)`입니다. 이는 만기 지급액이며, 옵션을 사는 데 지불한 가격까지 차감한 투자 손익과는 다릅니다.

처음부터 조기행사 여부까지 판단해야 하는 옵션을 선택하면 계산 과정이 복잡해집니다. 유럽형 콜은 만기 가격만으로 지급액이 결정되고, 일정한 가정 아래 Black–Scholes–Merton 공식이라는 비교 기준도 있습니다. 직접 만든 시뮬레이션이 제대로 작동하는지 확인하기에 적합한 출발점입니다.

여기서 평가하는 것은 **AAPL 주가를 기초로 설정한 가상의 유럽형 계약**입니다. 실제 거래소의 특정 AAPL 옵션 호가와 비교한 실습은 아닙니다. OIC도 옵션의 이론가격과 실제 시장 프리미엄을 구분하고, 조기행사 특성이 있는 미국형 옵션에는 다른 계산이 필요하다고 설명합니다. [OIC — Black–Scholes Formula](https://prd-web.optionseducation.org/advancedconcepts/black-scholes-formula)

## 2. 실제 데이터와 가정은 어떻게 구분했을까요?

실제 데이터는 Yahoo Finance에서 받은 AAPL의 2024년 일별 가격입니다. 현재 시점의 주가가 아니라 **2024년 12월 31일을 기준일로 두는 과거 시점의 계산**입니다.

| 항목 | 사용한 값 | 근거 |
|---|---|---|
| 가격 관측 기간 | 2024-01-02~2024-12-31 | 실제 일별 주가 |
| 가격 관측 수 | 252개 | 내려받은 자료 확인 |
| 로그수익률 관측 수 | 251개 | 인접한 가격의 변화 |
| 기준 주가 S₀ | 250.42달러 | 마지막 거래일의 일반 종가 |
| 연 변동성 σ | 약 22.3238% | 조정종가 로그수익률로 추정 |
| 행사가격 K | 250달러 | 가상 계약 조건 |
| 잔존만기 T | 0.25년 | 약 3개월로 지정 |
| 연속복리 금리 r | 연 4% | 계산을 위한 지정 가정 |
| 연속 배당수익률 q | 연 0.5% | 계산을 위한 지정 가정 |

**주가와 과거 변동성은 실제 자료에 근거하지만, 행사가격·만기·금리·배당수익률은 이번 실습에서 지정했습니다.** 특히 금리 4%와 배당수익률 0.5%를 해당 기준일에 관찰한 실제 수치처럼 해석하면 안 됩니다.

변동성 계산에는 배당·분할을 반영한 조정종가를 사용하고, 기준 주가에는 일반 종가를 사용했습니다. 조정종가는 수익률의 연속성을 살펴보기 위한 자료이고, 일반 종가는 기준일의 주당 가격 입력이기 때문입니다.

자료는 2026년 11월 5일에 조회한 과거 데이터입니다. 제공자의 조정·수정이 반영될 수 있어 당시 보관본을 이용한 백테스트와는 구분했습니다. 원자료와 조회 시각, 파일 해시도 로컬에 함께 저장했습니다. [Yahoo Finance — AAPL Historical Data](https://finance.yahoo.com/quote/AAPL/history/)

## 3. 주가 자료에서 변동성을 어떻게 추정할까요?

먼저 인접한 조정종가의 로그수익률을 계산합니다.

$$R_t=\ln\left(\frac{P_t^{adj}}{P_{t-1}^{adj}}\right)$$

가격이 252개라면 두 가격 사이의 변화는 251개입니다. 이번에는 이전 연도 마지막 가격을 추가로 가져오지 않았으므로 수익률도 251개를 사용했습니다.

이 수익률의 표본 표준편차를 계산하고, 연간 거래일 수를 252일로 가정해 연율화했습니다.

$$\hat{\sigma}=s(R_t)\sqrt{252}$$

일별 표준편차는 약 1.4063%, 연율화한 변동성은 약 22.3238%로 나왔습니다. 여기서 연율화는 일별 수익률의 분산을 시간에 비례해 환산하는 근사입니다.

```python
log_returns = np.diff(np.log(adjusted_close))
sigma = log_returns.std(ddof=1) * np.sqrt(252)
```

이 값은 **과거 실현변동성의 추정치**입니다. 시장 옵션가격에서 역산한 내재변동성이 아니며, 앞으로 3개월 동안 같은 변동성이 유지된다는 보장도 없습니다. 이번 모형에서는 이 추정치를 미래의 일정한 변동성 입력으로 사용했습니다.

## 4. 미래 주가를 많이 만들면 되는 걸까요?

여기서 중요한 구분이 있습니다. 과거 평균수익률을 그대로 넣고 미래 주가를 예측하는 것과, 옵션의 이론가치를 계산하는 것은 서로 다른 문제입니다.

이번에는 위험중립 평가를 사용합니다. 무차익 가격결정의 모형 안에서, 배당을 반영한 주가의 기대 성장률을 `r − q`로 두고 만기 지급액의 기대값을 무위험금리로 할인합니다. 투자자가 실제로 위험을 신경 쓰지 않는다는 뜻은 아닙니다.

만기 주가는 다음 식으로 생성했습니다.

$$S_T=S_0\exp\left[\left(r-q-\frac{\sigma^2}{2}\right)T+\sigma\sqrt{T}Z\right],\quad Z\sim N(0,1)$$

이 식은 주가가 기하브라운운동을 따른다는 가정에서 나옵니다. 로그주가의 변화가 정규분포를 따르므로 만기 주가는 로그정규분포를 따릅니다. 기하브라운운동의 구조는 [Karl Sigman의 강의자료](https://www.columbia.edu/~ks20/FE-Notes/4700-07-Notes-GBM.pdf)에서 확인할 수 있습니다.

이번에는 매일의 경로를 따로 생성하지 않았습니다. 유럽형 콜의 지급액에는 만기 가격만 필요하므로, 위 식으로 **만기 분포에서 직접 표본을 뽑았습니다.** 일정한 모수의 GBM 안에서는 이 방식으로 일별 시간 간격에 따른 이산화 오차를 피할 수 있습니다. 다만 GBM 자체가 실제 시장을 완벽하게 설명한다는 뜻은 아닙니다.

## 5. 몬테카를로 계산을 구현해봅시다

각 만기 주가에서 콜옵션 지급액을 계산하고, 현재가치로 할인한 뒤 평균을 구합니다.

$$\hat C_N=\frac{1}{N}\sum_{i=1}^{N}e^{-rT}\max(S_T^{(i)}-K,0)$$

핵심 코드는 다음과 같습니다. 아래에는 글의 표와 같은 100만 회 계산에 사용하는 난수 생성기를 명시했습니다.

```python
import numpy as np

S0, K, T = 250.42, 250.0, 0.25
r, q = 0.04, 0.005
sigma = 0.22323803369071848
N = 1_000_000

rng = np.random.Generator(np.random.PCG64(20261105))
z = rng.standard_normal(N)

ST = S0 * np.exp(
    (r - q - 0.5 * sigma**2) * T
    + sigma * np.sqrt(T) * z
)
discounted_payoff = np.exp(-r * T) * np.maximum(ST - K, 0)

price = discounted_payoff.mean()
se = discounted_payoff.std(ddof=1) / np.sqrt(N)
ci95 = (price - 1.96 * se, price + 1.96 * se)
```

seed를 고정하면 같은 환경에서 같은 난수를 생성해 결과를 재현할 수 있습니다. seed를 고정하는 것이 결과의 경제적 타당성을 보장하는 것은 아니므로, 뒤에서는 다른 seed로도 계산해봤습니다.

이번 실행 환경은 Python 3.9.6, NumPy 1.26.4입니다. 원자료의 정밀도를 유지해 계산하고 표에 표시할 때 반올림했습니다.

## 6. Black–Scholes와 얼마나 가까워졌을까요?

연속 배당수익률을 반영한 콜옵션 공식은 다음과 같습니다.

$$C=S_0e^{-qT}\Phi(d_1)-Ke^{-rT}\Phi(d_2)$$

$$d_1=\frac{\ln(S_0/K)+(r-q+\sigma^2/2)T}{\sigma\sqrt T},\qquad d_2=d_1-\sigma\sqrt T$$

여기서 Φ는 표준정규분포의 누적분포함수입니다. 같은 입력값을 넣은 공식의 결과는 **12.419241달러**였습니다.

몬테카를로 표본 수를 늘리면서 비교한 결과는 다음과 같습니다. 비교를 위해 같은 100만 개 난수의 앞부분을 각각 사용했습니다.

| 표본 수 | MC 추정값 | 표준오차 | 근사 95% 신뢰구간 | 공식과의 절대 차이 |
|---:|---:|---:|---|---:|
| 1,000 | 13.3555 | 0.6165 | 12.1472~14.5637 | 0.9362 |
| 10,000 | 12.5402 | 0.1844 | 12.1788~12.9015 | 0.1209 |
| 100,000 | 12.3426 | 0.0577 | 12.2295~12.4556 | 0.0767 |
| 1,000,000 | **12.4146** | **0.0183** | **12.3788~12.4504** | **0.0046** |

단위는 모두 기초주식 1주에 대응하는 달러입니다.

표본 수가 늘면서 추정의 흔들림이 줄어드는 모습을 확인할 수 있습니다. 다만 매번 표본을 늘릴 때마다 공식과의 절대 차이가 반드시 줄어드는 것은 아닙니다. 표본평균은 기준값의 위아래로 움직일 수 있습니다.

독립 표본을 사용하는 일반적인 몬테카를로에서는 표준오차가 대략 `1/√N`에 비례합니다. 오차 수준을 절반으로 줄이려면 표본 수가 약 4배 필요하다는 뜻입니다.

**두 값이 가깝다는 것은 같은 모형과 입력 아래에서 수치 계산이 일관된다는 근거입니다. 실제 시장가격이 12.4192달러라는 사실을 확인한 것은 아닙니다.**

## 7. 신뢰구간은 무엇의 불확실성을 보여줄까요?

여기서 12.3788~12.4504달러는 미래 주가가 들어갈 범위가 아닙니다. 실제 옵션 거래가격이 이 안에 있을 확률을 뜻하지도 않습니다.

고정한 모형과 입력 아래, 난수를 유한하게 뽑아서 평균을 계산할 때 생기는 **몬테카를로 추정 오차**를 나타내는 근사 신뢰구간입니다.

표준오차는 할인된 지급액의 표본 표준편차를 √N으로 나눠 구했습니다. 같은 방식으로 독립 실험을 반복한다면 이 구간 구성법이 참 모형 기대값을 약 95%의 비율로 포함하도록 하는 해석입니다. 이번에 계산한 모든 구간에는 공식값이 포함됐지만, 모든 seed에서 반드시 포함되어야 하는 것은 아닙니다.

이 구간에는 과거 자료로 추정한 변동성의 오차나, 금리·배당 가정의 불확실성, 실제 주가가 GBM과 다르게 움직이는 모형 위험이 포함되지 않습니다. 계산 횟수를 늘려도 이런 문제까지 사라지지는 않습니다.

## 8. 기존 민감도·시나리오 분석과 무엇이 다를까요?

앞서 DCF에서는 WACC와 영구성장률을 바꿔보거나, 매출과 이익률 등을 함께 바꾸는 시나리오를 비교했습니다. 이번 실습과 비교하면 차이가 더 분명해집니다.

| 방법 | 이번 옵션 실습에 적용한다면 | 답하려는 질문 |
|---|---|---|
| 민감도 분석 | 변동성 입력을 17.86%, 22.32%, 26.79%로 변경 | 특정 입력을 바꾸면 가치가 얼마나 달라질까요? |
| 시나리오 분석 | 주가·금리·배당·변동성을 묶어 조건별 계산 | 정해 둔 조건 조합에서는 얼마일까요? |
| 몬테카를로 가격계산 | 고정한 입력 아래 만기 주가를 반복 생성 | 모형상 지급액의 할인된 기대값은 얼마일까요? |

이번 몬테카를로에서는 **변동성 자체를 매번 무작위로 뽑지 않았습니다.** 변동성은 고정하고, 그 변동성이 만드는 만기 주가의 불확실성을 표본화했습니다.

따라서 기업가치의 입력들을 확률변수로 만드는 확률적 DCF와 이번 실습을 그대로 같은 구조라고 보면 안 됩니다. 몬테카를로는 계산 기법이고, 무엇을 확률변수로 둘지는 평가하려는 문제에 따라 달라집니다.

입력 가정의 영향도 따로 살펴보기 위해 변동성만 기준값의 0.8배와 1.2배로 바꾸고 공식으로 다시 계산했습니다.

| 연 변동성 | Black–Scholes 콜가치 |
|---:|---:|
| 17.8590% | 10.2182달러 |
| 22.3238% | 12.4192달러 |
| 26.7886% | 14.6229달러 |

이 범위는 변동성의 통계적 신뢰구간이 아니라, **선택한 입력 변화에 대한 민감도 예시**입니다. 표본 수를 늘리는 문제와 입력 가정의 타당성을 검토하는 문제를 구분할 수 있습니다.

- 콜·풋 공식의 풋콜패리티와 가격 상하한 확인
- 고정 난수에 대해 NumPy 계산과 별도의 스칼라 계산 대사
- 같은 seed 재실행 결과, 잘못된 입력과 누락된 가격의 처리 확인

이러한 내용과 데이터 검증 등을 포함해 자동 테스트 **17개가 통과했습니다.** 다만 테스트 통과는 실제 시장의 변동성이 일정하다는 증거는 아닙니다.

seed도 바꿔봤습니다. 각 10만 회의 콜가치는 다음과 같습니다.

| seed | 콜가치 |
|---:|---:|
| 20261105 | 12.3426 |
| 20261106 | 12.4477 |
| 20261107 | 12.4085 |
| 20261108 | 12.3409 |
| 20261109 | 12.3396 |

난수에 따라 결과가 달라지므로, 특정 실행 결과 하나만 제시하기보다 표본 수와 표준오차를 함께 기록하는 것이 좋습니다.

추가로 Z와 −Z를 짝지어 사용하는 **대칭변량법**도 적용했습니다. 100만 개의 만기 표본, 즉 50만 쌍에서 추정값은 12.3999달러, 표준오차는 0.0134달러로 나왔습니다. 일반 방식의 표준오차 0.0183달러보다 약 26.7% 작았습니다.

이때 서로 연관된 두 지급액을 독립 표본 2개처럼 취급하면 안 됩니다. 각 쌍의 평균을 독립 관측치로 보고 표준오차를 계산했습니다. 이번 실행에서는 표준오차가 줄었지만 공식과의 실제 절대 차이는 일반 방식보다 컸습니다. 분산을 줄이는 방법이 특정 실행의 절대 오차를 항상 줄여주는 것은 아닙니다.

## 10. 이번 실습에서 남은 것은 무엇일까요?

이번에는 실제 주가 데이터를 받아 수익률과 변동성을 계산하고, 가상의 옵션 조건을 정한 뒤, 몬테카를로 결과를 공식과 대사했습니다. 원자료·입력·난수 seed·계산 환경·CSV 결과와 차트도 로컬 파일로 남겼습니다.

확인한 것은 **주어진 모형 안에서 불확실한 지급액의 기대값을 수치적으로 계산하고, 그 오차와 재현성을 검토하는 과정**입니다.

실제 평가로 확장하려면 만기와 통화에 맞는 금리, 배당 일정, 내재변동성, 조기행사 등 계약 조건부터 다시 확인해야 합니다. 기업의 전환권이나 복잡한 조건부 지급구조에 적용할 때도 해당 권리의 조건에 맞는 모형이 필요합니다.

다음 단계에서는 추정 기간을 바꾸면 변동성이 얼마나 달라지는지 살펴보거나, 다른 지급구조를 적용해 어떤 경우에 몬테카를로가 더 유용해지는지 비교해볼 수 있습니다. 먼저 이렇게 비교 기준이 있는 문제로 계산을 검증한 경험이 그 출발점이 될 것입니다.
